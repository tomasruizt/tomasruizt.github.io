Qwen3.5 + Adaptive Verification

35B-A3B BF16 · one B300 per server, TP=1 · DFlash k=7 · SPEED-Bench throughput-1K · AIPerf 0.13.0

Each cell sends a fixed number of requests at fixed concurrency and waits for all of them to finish (trailing c1 is a drift sentinel). Two workers on two GPUs alternate AV off and on per repeat with a fresh server each time, so both modes run on both GPUs. Throughput counts output tokens that arrive in the steady-state window: from the c-th completion until the last request is issued. TPOT, ITL and TTFT are means over requests that start inside that window (ITL over all their chunk gaps). Commit 888ec6bb5745e6060fa2d6a424a37bebbbd84cb9.

Default CUDA graph capture sizes (up to 1,024 tokens on B300): steps with a prefill exceed them and run eagerly. 30 of 30 measurement cells passed all validity gates (c:requests = 1:24 8:96 32:192 64:320 128:512 1:24, measured 2026-10-16).
